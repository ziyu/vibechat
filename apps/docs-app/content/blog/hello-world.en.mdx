## Current Baseline

Vibe Chat now has a frontend scaffold based on TinyShip. The product web application lives in `apps/web-app` and uses React, TanStack Start, TanStack Router, Vite, and a PWA-oriented architecture.

### Current Scope

- One product web application and a separate documentation site.
- pnpm workspaces and Turborepo for project orchestration.
- Type checking, production builds, Docker, and CI baselines.
- Backend, database, authentication, and pricing integrations are deferred until the frontend scaffold is reviewed.

### Common Commands

```bash
pnpm dev
pnpm typecheck
pnpm build
pnpm dev:docs
```

Feature work follows the boundaries defined in `docs/stable/designs/vibechat-mvp-product-and-technical-design.md`.
