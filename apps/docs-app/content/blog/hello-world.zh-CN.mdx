## 当前基线

Vibe Chat 已基于 TinyShip 建立前端工程骨架。产品 Web 应用位于 `apps/web-app`，采用 React、TanStack Start、TanStack Router、Vite 与 PWA 技术路线。

### 当前范围

- 保留单一产品 Web 应用与独立文档站。
- 使用 pnpm workspace 与 Turborepo 管理构建。
- 提供 typecheck、生产构建、Docker 与 CI 基线。
- 后端、数据库、认证和定价暂不接入，待前端骨架验收后重新评审。

### 常用命令

```bash
pnpm dev
pnpm typecheck
pnpm build
pnpm dev:docs
```

功能开发以 `docs/stable/designs/vibechat-mvp-product-and-technical-design.md` 的产品边界为依据。
