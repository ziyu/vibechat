# 产品 API 参考

Vibe Chat Web 应用通过同源产品 API 组合 Better Auth、产品数据库和 Matrix/Synapse。这里记录当前已经实现的浏览器契约；第三方氛围市场、Runtime capability 和 Web Push 尚未开放。

## 身份验证

产品 API 读取 Better Auth 的 HttpOnly Cookie session，不接受客户端自建 Bearer token。浏览器请求应保持同源并携带 Cookie：

```ts
const response = await fetch('/v1/product-state', {
  credentials: 'include',
  headers: { accept: 'application/json' },
})
```

未登录时返回 `401 AUTH_SESSION_REQUIRED`。Matrix access token 只由 `/v1/session/bootstrap` 返回给当前浏览器内存中的 Matrix client，不应写入 localStorage、日志或其他产品 API。

## 当前端点

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/v1/session/bootstrap` | 当前产品资料与当前 Better Auth session 对应的 Matrix device bootstrap |
| `GET/PATCH` | `/v1/profile` | 读取或更新昵称、唯一用户名、头像与 onboarding 状态 |
| `GET` | `/v1/contacts` | 联系人、好友请求与屏蔽快照 |
| `GET` | `/v1/users/search?q=` | 搜索可发起好友请求的产品用户 |
| `POST` | `/v1/friend-requests` | 发起好友请求 |
| `POST` | `/v1/friend-requests/:id/accept` | 接受好友请求并确认 Matrix 邀请关系 |
| `POST` | `/v1/friend-requests/:id/reject` | 拒绝好友请求 |
| `PATCH` | `/v1/contacts/:userId` | 更新当前用户私有的联系人备注 |
| `POST/DELETE` | `/v1/blocks`、`/v1/blocks/:userId` | 屏蔽或解除屏蔽 |
| `POST` | `/v1/rooms` | 校验参与人和内置空间后幂等创建 Matrix 房间 |
| `POST` | `/v1/rooms/metadata` | 批量查询当前用户可访问的产品 room index |
| `GET/PATCH` | `/v1/product-state` | 用户通知、主题、语言、房间偏好与空间收藏快照 |
| `PUT` | `/v1/rooms/:roomId/preferences` | 保存当前用户对真实 Matrix 房间的置顶/静音状态 |
| `GET` | `/v1/spaces?locale=zh-CN` | 获取服务端官方内置空间目录及版本/能力信息 |
| `PUT` | `/v1/spaces/:spaceId/favorite` | 保存当前账号的官方空间收藏 |
| `GET` | `/api/credits/status`、`/api/credits/transactions` | 当前用户积分余额与账本 |
| `GET` | `/api/orders`、`/api/subscription/status` | 当前用户订单与权益 |
| `GET/POST` | `/api/affiliate/*`、`/api/withdrawal/*` | 推荐归因、佣金与 KYC 提现 |
| `POST` | `/api/payment/initiate` | 按服务端价格发起幂等结账 |
| `POST` | `/api/chat`、`/api/image-generate`、`/api/video-generate` | 带失败退款的 AI 生成 |
| `POST` | `/api/upload` | 校验类型和大小的登录态图片上传 |

支付成功/取消页只负责展示，履约权威来自验签后的 provider 回调。AI 任务和账本接口绑定当前用户，重试同一操作必须复用稳定 request ID。

## 产品状态示例

```json
{
  "preferences": {
    "notificationsEnabled": true,
    "theme": "system",
    "locale": "zh-CN"
  },
  "roomPreferences": [
    {
      "matrixRoomId": "!room:example.org",
      "pinned": true,
      "muted": false
    }
  ],
  "favoriteSpaceIds": ["space-campfire"]
}
```

空间目录中的 `source` 当前固定为 `builtin`。这表示该版本由产品服务内置，不代表第三方市场已经上线。

## 错误结构

产品 API 使用稳定错误结构，并在响应头和正文中返回相同的请求 ID：

```json
{
  "error": {
    "code": "PRODUCT_ROOM_NOT_FOUND",
    "message": "PRODUCT_ROOM_NOT_FOUND",
    "details": {},
    "requestId": "request-id"
  }
}
```

客户端必须根据 HTTP 状态和 `error.code` 处理失败，不能在服务失败时创建本地假用户、假房间或假 mutation。

## 数据权威

- Better Auth：账号与浏览器 session。
- 产品数据库：profile、社交关系、room index、用户偏好、房间偏好和空间收藏。
- Matrix/Synapse：房间 membership、timeline、关系事件、typing、read receipt、presence 和媒体 URI。
- 浏览器：仅保留 Matrix SDK 允许的 IndexedDB sync/timeline 缓存与非权威主题缓存。
