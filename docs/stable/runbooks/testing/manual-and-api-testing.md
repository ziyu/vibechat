# 手动与 API 测试 Runbook

> 生命周期：长期稳定
> 文档类型：Runbook
> 状态：生效
> 更新日期：2026-08-12
> 维护范围：`apps/web-app` 手动验收和 API 冒烟测试

## 前置条件

- 产品应用运行在 `http://localhost:8001`。
- 使用隔离的本地或测试数据库，不连接生产数据。
- 普通用户和管理员测试账户通过 seed 或受控注册创建，不把密码写进仓库。
- 外部支付、AI、邮件和短信使用沙盒或测试凭据。

## 基础页面冒烟

依次检查：

| 页面 | URL | 期望 |
| --- | --- | --- |
| 首页 | `/zh-CN` | 正常 SSR，无控制台致命错误 |
| 登录 | `/zh-CN/signin` | 表单和翻译加载 |
| 注册 | `/zh-CN/signup` | 校验、验证码开关与错误反馈正常 |
| 定价 | `/zh-CN/pricing` | 计划与币种符合当前配置 |
| Dashboard | `/zh-CN/dashboard` | 未登录跳转，登录后加载本人数据 |
| 管理后台 | `/zh-CN/admin` | 普通用户被拒绝，管理员可访问 |

同时访问 `/en`，确认英文路由和核心文案可用。

## API 冒烟

```bash
curl -i http://localhost:8001/api/health
curl -i http://localhost:8001/api/pricing/plans
curl -i http://localhost:8001/api/credits/balance
```

期望：

- 健康检查返回成功。
- 公开定价 API 返回稳定结构。
- 需要会话的 API 在无 cookie 时返回 `401`，不是服务器错误。
- 管理 API 对普通用户返回 `403` 或项目定义的等价拒绝响应。

## 认证与权限

1. 注册、登录、退出和密码重置流程可完成。
2. 未登录用户不能访问受保护页面或 API。
3. 普通用户不能调用管理 API。
4. 订阅保护页面在无订阅时跳转定价页。
5. 删除账户、修改密码等敏感操作要求当前会话和明确确认。

## 数据与支付

- 创建、查询和取消订单使用测试 Provider。
- Webhook 使用真实签名验证路径；前端回跳不能直接将订单标记成功。
- 重复 Webhook 不重复记账、发放积分或创建佣金。
- Provider 失败时检查积分退款、订单状态和日志 metadata。

## AI 与上传

- 缺少 Provider 配置时返回清晰错误，不泄漏密钥。
- 文件大小、MIME、数量和权限限制在服务端生效。
- AI 扣费在执行前完成，Provider 失败后按规则退款。

## 记录结果

手动测试用于发现视觉和集成问题，不能替代 E2E。发现稳定回归场景时，把验收标准加入 `tests/e2e/TEST-CATALOG.md`，再在真实 DOM 确认后补 Playwright 用例。
