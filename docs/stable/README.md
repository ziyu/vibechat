# 长期稳定文档

本目录保存已核验、需要持续维护的 Vibe Chat 文档。稳定是生命周期，设计、Runbook 等是文档类型，两者不能混为一谈。

| 类型 | 目录 | 回答的问题 |
| --- | --- | --- |
| 设计 | [`designs/`](./designs/) | 为什么这样设计，边界和取舍是什么 |
| Runbook | [`runbooks/`](./runbooks/) | 如何完成配置、运行、部署、测试和故障处理 |
| 参考资料 | [`references/`](./references/) | 参数、兼容性和查表信息是什么 |
| 发布说明 | [`release-notes/`](./release-notes/) | 某次发布实际改变了什么 |
| 计划 | [`plans/`](./plans/) | 当前认可的目标、顺序和里程碑是什么 |

文档进入本目录前必须与当前项目名称、单一 TanStack 产品应用、代码路径和命令一致。发生实质变更时先在 `../development/` 记录提案或核验工作，再更新对应稳定文档。

各目录的 `README.md` 是结构索引，不是内容文档类型，因此不填写生命周期元数据；其余稳定正文必须同时填写“生命周期：长期稳定”和对应文档类型。
