## 使用规则

- 新提案、RFC、阶段性方案和调研先放在这里。
- 文档必须写明状态、更新时间、维护范围和完成条件。
- 核验完成后，按文档类型整理并迁入 `../stable/`；不要把过程记录原样当成稳定文档。
- 结论被替代或工作取消后，迁入 `../archive/`，并记录替代文档或归档原因。
