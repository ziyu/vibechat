# 文档模板

模板按文档类型区分。先确定内容用途，再选择模板；不要用一种通用结构覆盖所有文档。

- [设计模板](./design-template.md)
- [Runbook 模板](./runbook-template.md)
- [参考资料模板](./reference-template.md)
- [发布说明模板](./release-note-template.md)
- [计划模板](./plan-template.md)
- [Active 实施伴随模板](./active-implementation-template.md)

这些文件是治理工具，不属于内容生命周期。使用时复制模板正文到 `docs/development/`，核验完成后再迁入 `docs/stable/<type>/`。
